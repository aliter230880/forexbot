# 🚀 START HERE — С чего начать?

## Вы только что получили интеллектуального форекс-бота!

### 📁 Что внутри?

Это **полностью функциональный** скальпер-бот для торговли золотом (XAUUSD) с:
- ✅ Машинным обучением (XGBoost)
- ✅ Многослойной аналитикой рынка
- ✅ Адаптивной торговой логикой
- ✅ Самообучением
- ✅ Risk management (Kelly Criterion)
- ✅ Telegram уведомлениями

## ⚡ Быстрый старт (5 минут)

### Шаг 1: Прочитайте это

📖 **[SAFETY.md](SAFETY.md)** — ОБЯЗАТЕЛЬНО! Риски и безопасность.

### Шаг 2: Установка

```bash
cd forex-scalper-bot
pip install -r requirements.txt
```

### Шаг 3: Настройка

```bash
cp .env.example .env
```

Отредактируйте `.env` — укажите данные **demo-счёта** MT5.

### Шаг 4: Проверка

```bash
python setup_and_test.py
```

### Шаг 5: Запуск

```bash
python main.py
```

✅ **Готово!** Бот работает на demo.
