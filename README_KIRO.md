# 🤖 Forex Scalper Bot — Kiro Build

## Что внутри папки `kiro/`

Полностью готовый к работе **интеллектуальный форекс-бот** для скальпинга золота (XAUUSD).

### 📦 Состав проекта:

- **26 файлов**
- **~5000+ строк кода**
- **60+ страниц документации**
- **9 модулей** торговой системы
- **ML-модель** (XGBoost) с 50+ фичами
- **Backtester** для тестирования на истории
- **Полная документация** на русском

---

## 🚀 Быстрый старт

### Шаг 1: Откройте папку

```bash
cd E:\AI\AI_folder\forexbot\kiro
```

### Шаг 2: Установка (автоматически)

**Windows:**
```bash
INSTALL.cmd
```

Или вручную:
```bash
pip install -r requirements.txt
cp .env.example .env
```

### Шаг 3: Настройка

Отредактируйте `.env` — укажите данные **demo-счёта** MetaTrader 5:

```env
MT5_LOGIN=ваш_demo_номер
MT5_PASSWORD=ваш_demo_пароль
MT5_SERVER=ваш_сервер
```

### Шаг 4: Проверка

```bash
python setup_and_test.py
```

### Шаг 5: Запуск

```bash
python main.py
```

## ⚡ Основные возможности

### Многослойная аналитика:
- Технический анализ (RSI, EMA, BB, ATR, MACD, Stochastic)
- Макро-корреляции (DXY, VIX)
- Sentiment analysis
- Микроструктура (спред, volume)

### Machine Learning:
- XGBoost модель
- 50+ признаков
- Автоматический ретрейнинг
- Обучение на собственных результатах

### Risk Management:
- Kelly Criterion для sizing
- Контроль просадки (max 3% в день)
- Trailing stop
- Правило "3 убытка подряд = стоп"

### Адаптивность:
- Детекция режимов: trending / ranging / high volatility
- Динамическая подстройка TP/SL
- Комбинированные сигналы (аналитика + ML)

## ⚠️ ВАЖНО!

### Перед запуском:

1. ✅ **Только demo!** — Минимум 2 недели на demo-счёте
2. ✅ **Прочитайте SAFETY.md** — понимание рисков обязательно
3. ✅ **MetaTrader 5** должен быть установлен и запущен
4. ✅ **Algo Trading** включен в MT5 (Tools → Options → Expert Advisors)

### Вы можете потерять деньги!

Форекс-торговля несёт **высокий риск**. Используйте только те деньги, которые можете позволить себе потерять.
