## Стратегия

| Параметр | Значение |
|----------|----------|
| Инструмент | XAUUSD.s (золото, суффикс брокера) |
| Сетка | 15 buy-limit уровней ниже цены, шаг **$4** |
| Лот | 0.02 (контракт 100 oz; маржа ~$18/уровень при 1:500) |
| Тейк пары | **серверный TP позиции +$4** (TRADE_ACTION_SLTP) — работает при выключенном боте |
| Спред | ~$0.30-0.40 → запас к шагу ×10 |

### Авто-механизмы (grid_engine.py)
1. **Авто-сдвиг вверх**: цена > верх сетки + 1 шаг → пересборка вокруг цены (кулдаун 10 мин). Открытые позиции/TP не трогаются.
2. **Поддержание снизу**: уровень сработал → добавляется ниже самого нижнего.
3. **Ремонт TP**: у живой позиции сбит/нет TP → переустановка; если bid ≥ TP → закрытие по рынку (Invalid stops обход).
4. **Тренд-фильтр**: ≤ -3%/24ч (H1) → отмена buy, пауза; > -2% → возврат. Персистентно в state.
5. **Margin guard**: watermark equity; -12% → полный стоп; margin level <300% → закрыть худшую; -5%/день → стоп до след. дня.
6. **Weekend flat**: пятница **23:00 UTC** всё закрыть (рынок у PU Prime до 23:55); воскресенье 22:05 UTC → возобновление.
7. **Аномалия-защита**: SELL-позиции с magic бота закрываются (мусор от старых багов).

### Синхронизация сделок (sync_fills)
- Позиция без пары → pair_open + серверный TP (аналог pair_buy_id — ticket позиции)
- Позиция пары исчезла → history_deals_get(position) → net PnL (profit+commission+swap+fee), costs пишутся отдельно

| Тип | Когда |
|-----|-------|
| 📊 СЕТКА (собрана/сдвинута) | все уровни, шаг, лот + **ATR-прогноз**: «волатильность ~$X/ч, первый уровень ~через N» |
| 🟢 УРОВЕНЬ СРАБОТАЛ | цена buy, TP, ETA до тейка, как повторить |
| ✅/🔻 ПАРА ЗАКРЫТА | PnL + итог нарастающим итогом |
| ⚠️ тренд/стоп/weekend | паузы и защитные события |

ATR: ATR-14 на H1 (`atr_usd_per_hour`), ETA = дистанция / ATR.

## Telegram-бот @Dim_forex_bot (демо: открытый доступ)

- Любой написавший → авто-подписка на уведомления + доступ к командам
- `/status` — сводка (работает и при выключенном терминале)
- `/start` — возобновить после стопа (сам поднимает терминал и сетку)
- `/stop` — **полный стоп**: ордера + позиции + закрытие терминала (taskkill; watchdog не воскресит, пока halted)
- Команды обрабатываются в отдельном try — торговые краши их не блокируют

## Управление

```bash
cd E:\AI\AI_folder\forexbot
.venv\Scripts\python.exe -m backend.main run        # бот (терминал поднимет сам)
.venv\Scripts\python.exe -m backend.main status     # сводка
.venv\Scripts\python.exe -m backend.main dry-run    # план сетки без ордеров
.venv\Scripts\python.exe -m backend.main stop-all   # всё отменить/закрыть + halt
.venv\Scripts\python.exe -m backend.webapp          # дашборд :8080
```

Дашборд: FastAPI читает только SQLite/state (не трогает MT5 → терминал не «воскресит»). Бот пишет snapshots раз в минуту (equity, маржа, сетка, тренд) для графика.

## Известные грабли (важно!)

1. **IPC timeout** (библиотека ↔ терминал): лечится чистой папкой данных + логин в GUI (кэш сервера брокера). После переустановок — `File → Открыть счёт → поиск PUPrime`.
2. **«AutoTrading disabled (10027)»**: галка «Разрешить алгоритмическую торговлю» применяется только **на живом сеансе** (Ctrl+O → Советники). После каждого нового старта терминала проверять `trade_allowed`.
3. Терминал **одноэкземплярный** на папку данных; библиотека спавнит свой — перед ручными делами убивать все terminal64.
4. Прямые правки `state.json` при живом боте бесполезны (затрёт) — только через `/start`/`/stop` или при остановленном процессе.
5. У отложенных ордеров MT5 нет привязки к позиции (position_id=0) — потому только серверные TP.
6. Терминал от MetaQuotes-инсталлера может прийти бетой (6120/6122) — с пакетом 5.0.6090 работает.
7. Гонки: chat_id подписчиков в `data/telegram.json` (не в state.json — его трёт цикл).
